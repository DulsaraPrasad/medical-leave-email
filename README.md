# Medical Leave Email & Letter Generator

A simple web-based tool designed for university students to prepare **medical leave emails and formal medical leave letters** quickly and easily.

## ✨ Features

- 📝 Enter student and contact details
- 📅 Select medical leave / absence dates
- 🏥 Add illness and medical information
- 📚 Select missed academic activities:
  - Lectures
  - Practicals
  - Tutorials
  - Quizzes
  - Assignments
  - Other activities
- 📧 Automatically generate a professional medical leave email
- 📋 Preview and copy the email
- 📄 Generate a formal medical leave letter
- 🖨️ A4-formatted formal letter
- ✍️ Space provided for the student's signature
- 📥 Generate/download the formal letter as a PDF
- 🇱🇰 English + Sinhala field descriptions for easier understanding
- 📱 Responsive design for desktop and mobile devices

## 🎯 Purpose

The purpose of this project is to make the process of preparing university medical leave documentation easier for students.

Instead of manually writing the same information repeatedly, students can enter their details once and generate the required documents.

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- GitHub Pages
- Client-side PDF generation

## 📖 How to Use

1. Open the website.
2. Fill in the required student information.
3. Enter the dates and reason for absence.
4. Select the academic activities that were missed.
5. Add the relevant subject/activity details.
6. Review the generated email.
7. Copy the email or open it in your email application.
8. Fill in the additional information required for the formal letter.
9. Preview the formal letter.
10. Generate the A4 PDF and sign it before submitting.

## 🔒 Privacy

The tool is designed to process the entered information **locally in the user's browser**.

Personal and medical information should not be entered on any website unless the user understands how that website handles their data.

## ⚠️ Disclaimer

This tool only helps generate the **format and content of medical leave documentation**.

Students should verify the generated information and follow their university's official medical leave procedures and submission requirements.
